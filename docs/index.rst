tiny_pacs documentation
=======================

``tiny_pacs`` is a small, pure-Python PACS (Picture Archiving and
Communication System). It implements a DICOM Service Class Provider (SCP)
for the most common services: Verification, Storage, Query/Retrieve and
Storage Commitment.
